# Chevvuru Rajini — Portfolio

Personal portfolio website for Chevvuru Rajini, CSE Undergraduate at Sridevi Women's Engineering College, Telangana.

**Live site:** https://chevvururajini.github.io/portfolio/

## Features
- Fully responsive (mobile + desktop)
- Dark / light mode toggle
- Skills, Projects, Experience, Achievements, Contact sections
- Resume download button
- No frameworks — pure HTML, CSS, JavaScript

## Deploy to GitHub Pages

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set source to `main` branch, `/ (root)`
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/`

## Update your info

| What to update | Where |
|---|---|
| GitHub / LinkedIn URLs | `index.html` — search `href="https://github.com/"` |
| Phone / Email | `index.html` — contact section |
| Resume file | Replace `resume.pdf` in root folder |
| Project GitHub links | `index.html` — each `.proj-links` section |
| Certificate view links | `index.html` — each `.cert-btn` href |
